## 配置与隔离

- 候选模型：`qwen3.7-text-embedding`，供应商 `qwen`，显式
  `EMBEDDING_DIMENSIONS=1024`、`EMBEDDING_INDEX_VERSION=1`。
- 保留现有切片策略、每批 10 条、15 秒 embedding 超时及不自动重试行为。
  不启用稀疏向量、查询 instruction、更长输入或更高维度。
- 最终 Compose 的新目录为 `/app/data/chroma_qwen37_1024_v1`，对应宿主
  `/opt/rag-kb/data/chroma_qwen37_1024_v1`。不改名、删除或覆盖旧 `chroma_db`。
- 模型接口地址仍为已确认的 DashScope 兼容地址，其新模型账号权限、实际路由和
  计费返回格式须在后续获准的真实接口验收中确认，不因本地适配通过就视为可用。

每个新 Chroma 集合记录身份 schema、供应商、模型、规范化接口地址、维度及索引
版本。打开默认集合及命名集合时核验；同维度但不同模型也拒绝。已有集合缺失身份
信息时同样拒绝，即使集合为空也不自动补标签。不能通过修改标签来把旧向量变成
新模型向量；应在独立目录中显式重建。索引错误不会回退为另一个模型。

身份校验在正常完整初始化获取 embedding 密钥之前执行；轻量元数据入口也受保护。
只捕获集合不存在这一类错误来创建集合，权限、存储、身份错误直接失败。
配置变更须重启进程，不能热改全局 Settings 后复用已取得的检索器对象。

嵌入缓存键包含供应商、模型、地址与维度。供应商返回及缓存命中的向量都检查
配置维度；文档批次还检查返回条数，错误结果不写入缓存或索引。
