- `EMBEDDING_MODEL=text-embedding-v3`，1024 维，index version 1。
- Compose 索引路径 `/app/data/chroma_v3_1024_v1`，宿主对应
  `/opt/rag-kb/data/chroma_v3_1024_v1`；不覆盖旧 `chroma_db` 或 qwen3.7 索引。
- 1000/200 切片、批量配置 10、embedding 15 秒、聊天 45 秒、问题 60 秒、零重试。
- 聊天仍使用 DeepSeek flash、非思考、最多 800 输出 token、温度 0.1。
- 使用真实 FastAPI lifespan、匿名 Secure Cookie、`/api/qa/ask` 路由、个人/全站次数
  准入及真实 SDK/供应商调用。ASGI 测试不监听公网端口，不替代浏览器/Nginx/TLS 验收。
- 关闭 QA 答案缓存；5 道题分别检查事实、可见的 3 条引用及拒答，不把“检索找到”
  当作“回答正确”。使用公开题集，不作为未知题集的泛化结论。

上限 1 元。均受共享 50 元/UTC 日金额限制。金额是保守预留，不是实际供应商账单。

`--workflow v3-regression`；随后使用 `--workflow v3-rebuild --review <review.json>`。

默认只输出计划，真实操作必须显式 `--execute`，且两阶段使用各自全新输出目录。

## 知识库交付边界

重建从公开 manifest 白名单逐文件核对 SHA256、复制原文并生成全新嵌入。固定
document_id、来源文件名和 `/app/data/uploads` 目标路径；Chroma 集合带模型身份。
关闭索引后重新打开，逐条验证 32 个 ID、全文、元数据及有限的 1024 维向量。
交付包仅含 `data/uploads`、`data/chroma_v3_1024_v1` 和文件 SHA256 清单。
不包含密钥、匿名身份/金额账本、QA 缓存、评测缓存或运行日志。

这是本地知识库交付候选，不代表已安装到服务器。目标 Linux 新镜像解包、索引读取
和真实应用回归仍是后续交付验收的一部分；Windows 验收不声明断电持久化保证。
付费账本必须另外保留并在迁移时核对，不得通过新服务器 bootstrap 清零当天预算。
